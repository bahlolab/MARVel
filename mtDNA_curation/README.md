# mtDNA Variant Curation

An R Shiny app for interactive curation of mitochondrial DNA (mtDNA) variants called from short-read sequencing data. Designed for clinical and research use in mitochondrial disease and rare disease cohorts.

## Overview

Variants are called using the [mitoHPC](https://github.com/bahlolab/mitoHPC) pipeline (Mutect2-based). This app loads per-sample VCFs, annotates them against reference databases, and presents an interactive filterable table for variant review.

## Features

- Multi-sample support — load a cohort manifest and review all samples in one table
- Per-sample variant allele frequency (VAF), depth, genotype classification (hom/het/low_het), and haplogroup
- Haplogroup-specific gnomAD allele frequencies (matched per variant row)
- Annotations from gnomAD v3.1, MITOMAP, and mitoTIP
- Variant filters: VAF threshold, gnomAD AF, PASS-only, strand bias, blacklist positions, hypervariable regions, synonymous variants, region, gene, sample ID
- Maternal inheritance analysis (maternal shared / de novo) using a PLINK FAM file
- Clickable gnomAD links per variant
- Export to CSV/Excel via table buttons

## Requirements

R packages:
```r
install.packages(c("shiny", "shinythemes", "DT", "data.table", "tidyverse"))
```

## Database setup

The app requires the following reference files organised under a `database/` directory:

```
database/
├── gnomad/
│   └── gnomad_chrM_hap_AF.tsv.gz        # generated by prepare_databases.R
├── MITOMAP/
│   ├── MutationsCodingControl_MITOMAP_Foswiki_reported_and_clin_conf_*_VAR.csv
│   └── MutationstRNA_MITOMAP_Foswiki_reported_and_clin_conf_*_VAR.csv
└── MitoTIP/
    └── mitotip_scores_27_04_2020_VAR.txt
```

**gnomAD and MITOMAP** files must be downloaded separately (see sources below) and preprocessed:

```r
Rscript prepare_databases.R   # generates gnomad_chrM_hap_AF.tsv.gz
```

MITOMAP and MitoTIP `_VAR` files are produced by the helper scripts `database/MITOMAP/add_VAR_MitoMAP.R` and `database/MitoTIP/add_VAR_MitoTIP.R`, which add a `VAR` join key (`{POS}_{REF}_{ALT}`) to the raw downloads.

## Input files

### Manifest (required)

A tab-separated file with columns:

| Column | Description |
|---|---|
| `SampleID` | Sample identifier |
| `FamilyID` | Family identifier (optional, for maternal analysis) |
| `SampleFolder` | Absolute path to the sample's mitoHPC output folder |

The app finds `*.mutect2.mutect2.00.vcf` recursively under `SampleFolder/out/`.

Generate a manifest from a results directory:
```r
Rscript generate_manifest.R
```

### FAM file (optional)

Standard PLINK 6-column FAM format. Required only for maternal inheritance filtering.

## Running the app

```r
shiny::runApp("mtDNA_curation")
```

On first load, enter the path to the `database/` directory in the **Database directory** field, then provide the manifest path and click **Load / Refresh**.

### HPC deployment

Set the `MTDNA_DB_DIR` environment variable to point to a shared database location:

```bash
export MTDNA_DB_DIR=/path/to/shared/database
Rscript -e "shiny::runApp('mtDNA_curation', port=3838)"
```

## Variant filters

| Filter | Default | Description |
|---|---|---|
| Min heteroplasmy level / VAF | 0.03 | Minimum variant allele frequency |
| Max gnomAD AF | 1 (off) | Filters on gnomAD_AF_hom or gnomAD_AF_het (and haplogroup-specific AF) depending on genotype |
| PASS only | off | Require FILTER = PASS |
| Exclude strand bias | on | Removes variants with `strand_bias` in FILTER |
| Exclude blacklist | on | Removes known artefact positions (301, 302, 310, 316, 3107, 5894, 10933, 16179, 16181–16183, 16188, 16189, 16192) |
| Exclude hypervariable | off | Removes variants in hypervariable regions |
| Exclude synonymous | off | Removes variants where MLC_consq = synonymous_variant |
| Region | All | Filter to CDS, rRNA, tRNA, or D-loop |
| Gene | All | Comma-separated gene names (e.g. `ND1,COX1`) |
| Sample ID | (blank) | Show variants for a single sample only |

## Genotype classification

| Genotype | VAF |
|---|---|
| hom | ≥ 0.95 |
| het | ≥ 0.03 and < 0.95 |
| low_het | < 0.03 |

## Output columns

Core: `SampleID`, `VAR`, `POS`, `REF`, `ALT`, `rsID`, `FILTER`, `VAF`, `DP`, `genotype`, `haplogroup`, `Region`, `Gene`, `COMPLEX`, `MLC_consq`, `AP`, `APS`, `MLC_score`, `MCC`, `Hypervariable`, `Homopolymer`, `is_INDEL`, `blacklist`

Annotations: `gnomAD_AF_hom`, `gnomAD_AF_het`, `gnomAD_AC_hom`, `gnomAD_AC_het`, `gnomAD_max_hl`, `gnomAD_hap_AF_hom`, `gnomAD_hap_AF_het`, `MITOMAP_locus`, `MITOMAP_disease`, `MITOMAP_status`, `MITOMAP_plasmy`, `mitoTIP_score`, `mitoTIP_quartile`
